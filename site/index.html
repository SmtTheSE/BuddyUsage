Install

Up and running in a minute.

Pick your computer. Every download is the latest release, straight from GitHub. BuddyUsage updates itself afterwards — one click inside the app.

Download for Apple Silicon Download for Intel

Not sure? Apple menu → About This Mac. "Apple M…" is Apple Silicon.

  1. Open the downloaded .dmg and drag BuddyUsage onto Applications.
  2. Open Applications and double-click BuddyUsage. The island appears on the right edge; its icon sits in the menu bar.
  3. Click a ring → Sign in. A normal browser window opens on that provider's own login page. Once per provider.
If macOS says it "could not verify" the app Open System Settings → Privacy & Security, scroll down and click Open Anyway, then confirm. This happens once — BuddyUsage is open source and not (yet) notarized with a paid Apple Developer ID. On older macOS: right-click the app → Open.
Prefer no prompt at all? Install from Terminal

Paste into Terminal (Applications → Utilities). Downloads without a browser, so there's no security prompt.

curl -fsSL https://raw.githubusercontent.com/SmtTheSE/BuddyUsage/main/install.sh | bash

Questions

Straight answers.

How does it know my usage?

It reads the same Settings → Usage page you'd open in a browser, in a hidden window that's signed in to your account. Nothing leaves your machine; there's no BuddyUsage server and no analytics.

Does it work on a free plan?

Yes. Gemini publishes usage limits on every plan, so free users get real gauges. Claude and ChatGPT don't show percentages on free plans — the ring says "Free" and the card explains, instead of showing an error.

Why does my Mac warn me the first time?

The app isn't notarized with a paid Apple Developer ID, so Gatekeeper asks once. It's a standard step for open-source Mac apps: System Settings → Privacy & Security → Open Anyway. The Terminal installer avoids the prompt entirely.

Will it slow my machine down or hammer the sites?

It polls every few minutes and otherwise reacts to real events — you using a tool, a limit resetting, waking from sleep. Every trigger funnels into one fetch per provider, so nothing is requested twice.

Can I move it, hide it, change it?

Drag it anywhere — it snaps to the nearest edge of any display. The ‹ handle collapses it to a slim tab. Settings lets you pick providers, refresh rate, edge, appearance, and an optional menu-bar readout.

How do updates work?

BuddyUsage checks GitHub Releases in the background. When there's a new version you'll see a dot on the island and an Update button — one click installs it and restarts. A download link is always there too.
